# 有我在作品集媒体

## 内容

- `screenshots`：6 张使用 Demo 账号和模拟文本生成的产品截图。
- `有我在APP演示视频.webm`：约 88 秒、无旁白的产品演示视频，包含字幕和能力边界说明。

## 脱敏规则

- 不展示 API Key、环境变量、本地文件路径或浏览器开发工具。
- 不使用真实姓名、联系方式、聊天记录或健康信息。
- High Risk 内容明确标注为产品安全流程演示。
- 守护通知明确说明为站内模拟，不宣称真实送达。

## 重新生成

先启动本地应用，再执行：

```bash
pnpm capture:portfolio
```

脚本使用系统已安装的 Microsoft Edge，不下载独立浏览器。
